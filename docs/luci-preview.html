Airhand 远程桌面

中继服务器和网页控制台都跑在这台路由器上。被控电脑安装 Airhand 客户端，把中继地址指向本机，然后用浏览器打开本机端口即可控制。

中继服务器

QUIC，UDP 4433。只负责分配控制码和转发字节，端到端加密在两端完成。
UDP 端口，默认 0.0.0.0:4433。被控电脑和网页控制台都连这个端口。
同一台被控电脑最多允许几个控制端同时连接。
自动生成证书时写入的域名或 IP，逗号分隔。客户端按指纹校验，这里通常不用改。
证书和 SQLite 数据库（控制码绑定表）所在目录，必须可写并且能持久保存。

网页控制台

TCP 8080，同一个端口同时支持 HTTP 和 HTTPS。从别的电脑访问必须用 https://。
同一个端口同时支持 HTTP 和 HTTPS；从别的电脑访问必须用 https://，否则浏览器拿不到 WebCodecs 硬解。
网页控制台连接的中继，默认就是本机的中继。
留空则第一次连接时记住中继证书（TOFU）。中继就在本机时影响不大；中继将来换证书，留空反而更省事。
被控电脑托盘里「谁在控制」显示的名字。
浏览器打开时会弹出登录框，用户名随意。留空表示任何人都能访问控制台（危险）。
写进自签名证书的域名或 IP，逗号分隔。填你实际访问用的地址，浏览器至少不会报「名称不匹配」（自签名警告仍然会有）。
证书、控制台身份（controller-key.txt）和中继信任记录所在目录。
i 改完配置需要重启对应服务才生效。中继换了证书，所有客户端都要重新填指纹。
