Airhand 远程桌面

中继服务器与网页控制台均在本机运行。被控端安装 Airhand 客户端后，将其配置中的中继地址指向本机，即可通过浏览器访问本机端口进行控制。

中继服务器

QUIC / UDP 4433。仅负责分配控制码与转发字节，端到端加密由两端协商完成。
UDP 监听地址，默认 0.0.0.0:4433。被控端与网页控制台均连接此端口。
单台被控端允许同时建立的最大会话数，默认 4。
自动签发证书时写入的域名或 IP，以逗号分隔。客户端以指纹方式校验，通常无需修改。
存放 TLS 证书与 SQLite 数据库（控制码绑定表）的目录。须可写且能持久保留。

网页控制台

TCP 8080。同一端口同时提供 HTTP 与 HTTPS，远程访问须使用 https://。
TCP 监听地址，默认 0.0.0.0:8080。同一端口同时提供 HTTP 与 HTTPS；远程访问须使用 https://，否则浏览器无法启用 WebCodecs 硬件解码。
网页控制台所连接的中继地址，默认为本机中继。
留空时于首次连接记录中继证书（TOFU）。中继位于本机时影响有限；若中继更换证书，留空可免于手动更新。
被控端托盘「当前控制方」中显示的名称。
设置后浏览器将弹出 HTTP 基本认证对话框，用户名任意。留空则不校验身份，任何可达者均可使用控制台。
写入自签名证书的域名或 IP，以逗号分隔。建议与实际访问地址保持一致，以避免名称不匹配告警（自签名证书本身的告警仍会出现）。
存放 HTTPS 证书、控制台身份（controller-key.txt）与中继信任记录的目录。
i 配置修改后须重启对应服务方可生效。若中继证书更换，所有客户端均需重新填写指纹。
